## Boundary rules

Supported integrations define authentication, permissions, configuration, version support, failure behavior and data boundaries. Microsoft, Xbox, Minecraft/Mojang, Discord, payment providers, webhooks and Minecraft servers remain external systems.

Real bot tokens, webhook credentials, payment secrets, API secrets, private keys, database credentials, personal information and internal infrastructure details stay private.
